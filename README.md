# 🖥️ 30 Days of Operating Systems

A day-by-day journey through Operating System concepts — from the absolute basics to processes, memory management, scheduling, deadlocks, and file systems. Each day comes with a detailed write-up here in the repo, and a shorter recap posted on LinkedIn.

## 🎯 Why this repo?

Operating Systems is one of those subjects that's easy to memorize and hard to actually *understand* — until you sit down and ask "wait, why does this even exist?" for every concept. That's the goal of this series: build genuine intuition, one topic at a time, and document it publicly so it sticks.

## 📚 How it's organized

Each day lives in its own file, named `day-XX-topic-name.md`, containing:
- The core concept explained in plain language
- The "why" behind the concept — what problem it solves
- Notes and diagrams from my study material
- Key takeaways
